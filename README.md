# Superconductivity Classification Project

**Authors:** Tomáš Tisovský, Jakub Ivácek  
**Course:** OZNAL — FIIT STU  
**Date:** 2026-05-01

## Overview

Binary classification of superconducting materials as **high-temperature** (`high_tc`, critical_temp ≥ 77 K) or **standard** (`non_high_tc`) using 81 numerical material descriptors from the [UCI Superconductivity Dataset](https://archive.ics.uci.edu/dataset/464/superconductivty+data).

The 77 K threshold corresponds to the boiling point of liquid nitrogen — materials above it can be cooled with liquid nitrogen rather than the more expensive liquid helium.

## Dataset

| File | Description |
|------|-------------|
| `train.csv` | 21 263 superconductors × 81 numerical features + `critical_temp` |
| `unique_m.csv` | Chemical formulas for each material |

## Scenarios

### Scenario 1 — Model comparison
Six classifiers evaluated on the same train/test split with two thresholds (0.5 and Youden):

| Model | Features | AUC |
|-------|----------|-----|
| Logistic Regression A | 20 (EDA top-20) | 0.928 |
| Logistic Regression B | 9 (deduplicated) | 0.921 |
| SVM A | 20 (EDA top-20) | 0.916 |
| SVM B | 9 (deduplicated) | 0.926 |
| **Random Forest** | **81 (all)** | **0.979** |
| Decision Tree | 81 (all) | 0.955 |

**Best model:** Random Forest with Youden threshold — AUC 0.979, sensitivity 0.954, only 36 missed superconductors vs 235 false positives.

### Scenario 3 — Feature selection
Three regularised logistic regression methods compared on all 81 features:
- Backward stepwise selection
- Lasso logistic regression (`lambda.min` and `lambda.1se`)
- Elastic net logistic regression (`lambda.min` and `lambda.1se`)

## How to Run

1. Place `train.csv` and `unique_m.csv` in the project root.
2. Open `oznal_critical_tmp_project.Rproj` in RStudio.
3. Knit `Superconductivity_Classification_Project.Rmd` to HTML or PDF.
4. To run the Shiny app: `shiny::runApp("app.R")`.

Required packages are installed automatically by the setup chunk in the Rmd.
